# AvatarEdited для MTG Forge Adventure

В настройках Adventure выберите AvatarEdited и начните новую кампанию. Карта 700 × 700, биомы, города, подземелья, 53 задания, 464 противника и параметры сложности взяты из Shandalar. Проверенная сборка Forge — 2.0.16-SNAPSHOT-11.08, Java 21.

## Пул и колоды

TLA и TLE дают 524 различных имени. Штатный список ограничений Adventure исключает из генерируемого пула два из этих имён, Sol Ring и Arcane Signet. В готовых DCK каждая строка указывает имя, выпуск и номер иллюстрации. Каталог локальных печатей находится в avatar-printings.tsv. Базовые земли и альбом земель используют TLA.

Пять прототипов находятся в decks/pilot. Allies служит белым стартом и колодой Human Captain, Jet — колодой Barbarian, Earth — колодой Elf, Air — первым вариантом Adept Blue Wizard, Ozai — колодой Tibalt. В enemy-mapping.tsv указаны исходный путь, конечный DCK и выбранные ключевые карты каждой встречи, включая вторую стадию Goblin Pack и десять дополнительных путей с карт подземелий. У 40 боссов вручную выбраны ключевые карты. Например, Emrakul разгоняется через Badgermole Cub и Shared Roots к Cityscape Leveler, а Sliver Queen собирает армию токенов с Rhys the Redeemed и Invasion Reinforcements. У Слобада одна партия на матч для совместимости с эффектом фабрики в этой версии Forge.

Standard предлагает пять стартов по 40 карт. В Constructed объединены два одноцветных тематических пакета, в Pile — два пакета разных цветов. Состав зависит от выбранного цвета и сложности. Commander предлагает пять колод по 100 карт с легальным командиром и ограничением в один экземпляр небазовой карты. При создании стартов генератор разрешает имя по каталогу Avatar. Поэтому Brainstorm получает TLE, Hook Swords — TLE, Jet, Freedom Fighter — TLA.

## Магазины, трофеи и события

В обычном городе работают таверна и три продавца. У продавца одиночных карт три независимых слота C, U, U и четвёртый слот с весами 30 C, 50 U, 18 R, 2 M. Все четыре пула имён попарно разделены. В пустошах специализация лавки существ расширена до бесцветных артефактов. Остальные пять цветов имеют как обычную витрину, так и витрину существ своего цвета. У продавца бустеров один штатный Play Booster TLA, в котором возможна печать TLE. Третья лавка продаёт земли, а в пустошах — снаряжение. Витрина привязана к точке мира, повторный вход сохраняет предложение.

Именные награды перечислены в reward-mapping.tsv. В enemy-reward-fixes.json и reward-fixes.json сохранены замены фильтров, для которых движок обнаружил пустую выдачу. При нехватке подходящего трофея в конкретной колоде врага генератор может выбрать карту той же редкости из общего пула. Свитки, сундуки и объекты бустеров на карте получают локальные правила. Текстовые списки наград в квестах и на картах обрабатываются рекурсивно.

Для Draft и Sealed используется блок Avatar TLA с оригинальным рецептом TLA. Событийный Jumpstart выключен. Forge выбирает специальные пакеты из глобальной базы по коду земли блока и пропускает локальный список тем. Штатная тема Librarian содержит Brainstorm из DSC. Когда игра выбирает формат Jumpstart для организатора, событие недоступно. Стартовые колоды из тематических пакетов собраны заранее и содержат исправленные печати.

Chaos строит случайную колоду по правилам клиента. Custom импортирует выбранную пользователем колоду. Для кампании с гарантированным пулом выбирайте Standard, Constructed, Pile или Commander. Doppelganger копирует существ с помощью Clone и Sakashima of a Thousand Faces. Копирование всей колоды игрока отключено, поскольку для маленьких колод Forge выдаёт The Cheese Stands Alone напрямую. Призванные токены, эмблемы, временные карты от экипировки и командные эффекты боссов действуют по правилам исходной встречи. Например, фабрика сохраняет свой эффект, а предмет Black Lotus может создать перманент на поле боя. Карта, которую выдаёт свиток в коллекцию, проходит через замену именной награды.

## Проверка установленной сборки

В macOS с zsh начните в папке res. Команды создают отдельный профиль, каталоги колод, кэша и пользовательских данных. Для сборки мода нужны оба JAR текущей установки. Для самой игры генератор и компилятор не требуются.

```sh
resources="$PWD"
mobile=( "$resources"/../forge-gui-mobile*.jar )
desktop=( "$resources"/../forge-gui-desktop*.jar )
scratch=$(mktemp -d)
cd "$scratch"
mkdir -p home user/adventure user/preferences cache decks
ln -s "$resources" res
printf 'userDir=%s/user\ncacheDir=%s/cache\ndecksDir=%s/decks\n' "$PWD" "$PWD" "$PWD" > forge.profile.properties
echo '{"plane":"AvatarEdited"}' > user/adventure/settings.json
plane="$resources/adventure/AvatarEdited"
cpj=".:$mobile[1]:$desktop[1]"
javac -cp "$cpj" -d . "$plane"/tools/{Starts,VerifyPlane,Playthrough,ExportCardIndex,TestProfile}.java
vm=(java -Xmx3g -Duser.home="$PWD/home" -cp "$cpj")
python3 "$plane/tools/check_resources.py" --loot "$PWD/loot.tsv"
for variants in false true; do
  "${vm[@]}" -Djava.awt.headless=true Starts AvatarEdited "$variants" || break
  "${vm[@]}" -Djava.awt.headless=true VerifyPlane loot.tsv "$variants" || break
done
```

Чтобы пересобрать ресурсы после изменения колод или правил, в том же временном каталоге выполните обе команды и повторите проверки выше.

```sh
"${vm[@]}" -Djava.awt.headless=true ExportCardIndex rules.tsv TLA,TLE
python3 "$plane/tools/build_plane.py" rules.tsv
```

Playthrough запускает графический клиент в тестовом профиле, входит в город, проверяет повторную витрину и разыгрывает дуэль на фабрике. После начала партии решения за игрока принимает ИИ. Для полной проверки требуется выиграть матч. Проигрыш не выдаёт награду.

```sh
"${vm[@]}" --add-opens java.base/java.util=ALL-UNNAMED --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.desktop/java.awt=ALL-UNNAMED Playthrough
```

Для повторения боя колодой поздней игры добавьте к команде Java параметр `-Davatar.test.deck=Emrakul` перед `Playthrough`. После посещения города тест добавляет недостающие карты в коллекцию временного героя и выбирает готовую колоду Emrakul. Для проверки белого старта используйте `-Davatar.test.deck=Allies`. Начальные жизни, колода Слобада и правила фабрики берутся из того же игрового режима.

С параметром `-Davatar.test.dragon=true` тот же сценарий проверяет встречу с Ancient Silver Dragon в сгенерированном мире. У дракона золото выпадает с вероятностью 70%, карты гарантированы.

Параметр `-Davatar.test.gear=true` выдаёт временному герою и экипирует Armor of the Hivelord, Black Lotus и Mox цвета тестовой колоды. После получения награды Playthrough сравнивает количество каждой выданной карты с коллекцией до боя и проверяет издания всех прибавившихся карт.
